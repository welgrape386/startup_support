# 자격조건 스키마 (최종 v1.1, 2026-11-18)

공고 원문에서 **신청 자격 조건**을 뽑아 담는 구조. 판정 코드가 이 값과 사용자 필드를 비교해 신호등(🟢🟡🔴⚪)을 내고, 판정하지 않는 조건은 체크리스트로 보여준다.
우대·지원내용·서류·일정은 **안내정보 스키마**(`docs/안내정보_스키마.md`)에 있다.

- 이 문서는 서비스 데이터 62건에 **실제로 쓰인 칸과 값만** 정리한 확인용 문서다. 62건에서 한 번도 안 쓰인 값과 그 규칙은 뺐다 (8절)
- 각 표의 "62건" 칸 = 서비스 62건(최상위 + 트랙 + 대안조건 선택지)에서 그 값이 나온 횟수
- 판정 규칙: `docs/판정규칙_최종.md` (나주희 원문 `판정규칙_나주희_1118.md`에서 사용자 필드 이름을 이 문서 4절에 맞춘 판). 이 문서의 "판정"은 그것을 칸별로 요약한 것
- 이전 버전 전체 규칙: `docs/스키마.md` (v0.7)

| 항목 | 내용 |

## 1. 공통 규칙

### 1-1. 상태

| 상태 | 뜻 | 판정 |
| --- | --- | --- |
| `있음` | 원문에 조건이 있음 | 값으로 비교 |
| `없음` | 원문에 조건이 없음 (제한 없음) | 통과 |
| `불명확` | 언급은 있지만 값으로 정리할 수 없음 | ❔ |
| `대안조건` | "A 또는 B"라서 `대안조건` 목록에서 판정 | 이 칸은 건너뜀 |

- `없음`·`대안조건`이면 나머지 필드는 `null`
- `불명확`이면 알 수 있는 값만 채우고 `근거`는 꼭 적음

### 1-2. 근거
- 원문 텍스트(`output/texts/{공고ID}.txt`)를 **글자 그대로** 복사. 요약·의역 금지
- 판단에 필요한 최소 구간 (보통 한 문장)
- 코드가 원문에 실제로 있는지 확인. **원문에서 못 찾은 근거의 조건은 '미기재'로 보고 판정에 안 씀** (평가 15건 기준 일치율 100%)

### 1-3. 값
- 숫자는 정수, 기간은 개월 (3년 = 36). 원문 숫자 그대로 ("40세 미만" → `max: 40, 경계_max: 미만`, 39로 바꾸지 않음)
- 날짜는 `YYYY-MM-DD`
- `기준일`: `공고일` / `접수마감일` / `명시없음` (62건에서 쓰인 값). `명시없음`이면 판정 기준일(2026-10-16)

### 1-4. 조건 결합
- 기본은 AND (나열된 조건을 모두 만족)
- "A 또는 B" → `대안조건`
- 대상마다 조건이 다르면 → 공통은 최상위, 다른 것은 `트랙`

## 2. 판정 요약

**LLM은 조건을 뽑기만 하고, 판정은 코드가 한다.** (원문 → LLM 추출 → JSON → 판정 코드가 사용자 필드와 비교)

### 2-1. 조건 결과 → 신호등

조건 하나의 결과: `✅ 충족` / `🟡 바꾸거나 채우면 가능` / `❌ 불충족` / `❔ 확인 필요`

| 신호 | 의미 | 조건 |
| --- | --- | --- |
| 🔴 | 신청 불가 | `❌`가 1개 이상 |
| ⚪ | 확인 필요 | `❌` 없음, `❔`가 2개 이상 (또는 성별·대상 자격 전용 공고인데 사용자가 안 적음) |
| 🟡 | 조건부 | `❌` 없음, `🟡` 또는 `❔`가 1개 이상 |
| 🟢 | 신청 가능 | 판정한 조건이 모두 `✅` |

- 우선순위 🔴 > ⚪ > 🟡 > 🟢. **하나라도 ✅가 아니면 🟢 금지** (false green 최소화)
- 판정 조건을 하나도 뽑지 못한 공고 → ⚪ (사유: 자격 조건 미기재)
- 🟡·⚪에는 [조건] 문구를 붙임 (예: "성북구에서 창업하면 신청 가능", "개인사업자만 신청 가능")

### 2-2. 무엇을 판정하나

| 구분 | 칸 | 신호등 |
| --- | --- | --- |
| **판정 조건 (필수 4개, 항상)** | 나이, 지역, 창업단계(사업자등록·업력), 업종 | 반영 |
| **판정 조건 (사용자가 적었을 때)** | 신청자_유형(개인사업자·법인), 성별, 특수자격 | 반영. 안 적었으면 전용 공고에서만 신청자_유형 🟡, 성별·특수자격 ⚪ |
| 상세 화면 체크리스트 | 기업규모, 보유요건, 제외대상, 창업이력, 기타조건 | 영향 없음 |

### 2-3. 칸별 사용 (62건 중 공고 수)

| 칸 | 공고 수 | 판정 |
| --- | --- | --- |
| 신청자_유형 | 62 | 판정 (적었을 때) |
| 사업자등록 | 61 | 판정 (창업단계) |
| 기타조건 | 53 | 체크리스트 |
| 제외대상 | 46 | 체크리스트 |
| 업종 | 42 | 판정 |
| 기업규모 | 39 | 체크리스트 |
| 업력 | 33 | 판정 (창업단계) |
| 트랙 | 29 | 트랙별로 판정해 가장 좋은 결과 |
| 보유요건 | 21 | 체크리스트 |
| 대안조건 | 15 | 선택지 중 가장 좋은 결과 |
| 지역 | 15 | 판정 |
| 나이 | 9 | 판정 |
| 창업이력 | 4 | 체크리스트 |
| 특수자격 | 2 | 판정 (적었을 때) |
| 성별 | 0 | (62건 모두 `없음`) |

### 2-4. 트랙·대안조건 합치기
- `대안조건`: 선택지 중 **가장 좋은** 결과 (✅ > 🟡 > ❔ > ❌)
- `트랙`: 트랙마다 따로 판정해 **가장 좋은** 신호등과 트랙 이름을 같이 보여줌 (🟢 > 🟡 > ⚪ > 🔴)
- 확인 순서 (🔴 사유 표시용): 창업단계 → 신청자_유형 → 지역 → 나이 → 성별 → 업종 → 대상 자격

## 3. 칸별 정의

### 3-1. 신청자_유형 (62건)

| 필드 | 값 | 62건 |
| --- | --- | --- |
| `값` (list) | `법인` / `개인사업자` / `예비창업자` / `기타` / `기관·단체` / `대학생` | 64 / 62 / 17 / 4 / 3 / 1 |

- "기업", "소상공인", "중소기업"처럼 형태가 없으면 `["개인사업자", "법인"]`
- 규모(소상공인 등)는 `기업규모`에
- 트랙마다 유형이 다르면 트랙 조건 안에 따로

**판정** (사용자 `사업자_형태`)
- `["개인사업자", "법인"]`처럼 둘 다면 누구든 됨 (빈칸으로 봄)
- "법인만"처럼 하나뿐인 전용 공고: 적었으면 일치 ✅ / 불일치 ❌, 안 적었으면 🟡 [법인만 신청 가능]
- 예비창업자는 전용 공고가 사업자등록 필수라 창업단계에서 이미 ❌ (사후등록 + 법인만이면 🟡 [선정 후 법인 설립 필요])
- `대학생` 대상은 사용자 `특수자격: 대학생`과 비교

### 3-2. 나이 (9건)

| 필드 | 값 | 62건 |
| --- | --- | --- |
| `min`, `max` | int | max: 39(6), 69, 34 / min: 15(2), 19(2), 40 |
| `경계_min` / `경계_max` | `이상` / `이하`, `미만` | 이상 5 / 이하 8 |
| `나이_기준` | `만나이` / `명시없음` | 8 / 2 |
| `기준일` | `공고일` / `명시없음` | 3 / 7 |
| `출생일_범위` | `{from, from_경계, to, to_경계}` | 1 |
| `대상` | `대표자` / `신청자_본인` / `채용대상` / `구성원_전원` | 5 / 2 / 2 / 1 |

- 출생일로 적히면 `출생일_범위` (`이후`·`이전`은 그 날 포함, `후`·`전`은 제외, 물결표는 양끝 포함)

**판정** (사용자 `만나이`)
- 기준일의 가능한 생일 범위로 비교: 조건 안 ✅ / 밖 ❌ / 걸침 ❔
- "N세 이하·이내"는 N세 포함, "N세 미만"은 N-1세까지
- 숫자와 출생일이 둘 다 있으면: 둘 다 ✅ → ✅, 하나만 ✅ → ❔, 둘 다 ❌ → ❌
- `대상`이 대표자(신청자)일 때만 비교. `채용대상`(직원 나이)은 비교하지 않음
- 나이가 비어 있으면 ❔ + 되묻기

### 3-3. 성별 (0건)
- 62건 모두 `상태: 없음`. 필드는 `값`(`여성`/`남성`), `대상`
- **판정**: 적었으면 일치 ✅ / 불일치 ❌, 안 적었으면 ⚪ [여성 대표자만 신청 가능]. 대상이 대표자일 때만

### 3-4. 지역 (15건)

| 필드 | 값 | 62건 |
| --- | --- | --- |
| `범위` | `[{"시도", "권역", "시군구"}]` | 서울특별시 17 (구 단위 8), 강원특별자치도 1 |
| `유형` (list) | `사업장소재지` / `사업자등록지` / `본사소재지` / `거주지` | 9 / 6 / 2 / 1 |
| `유형_결합` | 유형이 2개 이상일 때 `하나만` = 하나만 맞으면 통과 ("본사·지사 중 1곳 이상 서울"). 유형이 1개면 null | 2 (124045, 127132) |
| `사후충족_허용` / `사후충족_기한` | `true` / `선정후` | 1 (127032) |

- "전국"이면 `상태: 없음`
- 시도는 공식 명칭 ("서울특별시"), 구 공고는 `시군구`까지 ("성북구"). `권역`은 62건에서 안 씀

**판정**
| 공고 유형 | 비교할 사용자 필드 |
| --- | --- |
| `거주지` | `거주지` |
| `사업장소재지`·`사업자등록지`·`본사소재지` | 기창업자 `사업장소재지` / 예비창업자 `창업예정지` |

| 사용자 | ❌ | 🟡 | ✅ |
| --- | --- | --- | --- |
| 예비창업자 | 타지역(서울 외 시도) 공고 | 서울 공고에서 거주지 또는 창업예정지 불일치 (서울 안 다른 구) | 모두 일치 |
| 기창업자 | 사업장 불일치 (사업장 이전 조건 공고 포함), 타지역 공고 | 거주지만 불일치 | 모두 일치 |

- 공고 `시군구`가 null이면 시도 전체, 있으면 구까지 일치해야 함. `범위`가 여러 개면 하나만 맞으면 됨
- `유형_결합: 하나만`이면 유형별 결과 중 가장 좋은 것
- 필요한 사용자 칸이 비어 있으면 ❔ + 되묻기. 공고 `불명확`도 ❔

### 3-5. 업력 (33건)

| 필드 | 값 | 62건 |
| --- | --- | --- |
| `min_개월`, `max_개월` | int | max: 84(15), 36, 60, 120 (각 3) / min: 2, 6, 12, 24, 36 |
| `경계_min` / `경계_max` | `이상` / `이하`, `미만` | 12 / 18, 6 |
| `업력_기준` | `명시없음` / `개업일` / `법인설립등기일` / `사업자등록일` | 25 / 11 / 3 / 1 |
| `기준일` | `공고일` / `명시없음` | 13 / 27 |
| `창업일_범위` | `{from, from_경계, to, to_경계}` | 9 |

- "3년 이내" → `max_개월: 36, 경계_max: 이하` / "3년 미만" → `경계_max: 미만`
- 날짜로 적히면 `창업일_범위` ("2025. 1. 1. 이후 창업" → `from: 2025-01-01, from_경계: 이후`). 개월과 날짜가 함께 있으면 둘 다
- 업력 상한에 예외가 붙으면 ("7년 이내, 벤처기업은 초과 가능") → `대안조건` (10건)

**판정** (사용자 `업력_개월`, 창업단계의 일부)
- 기창업자: 공고 범위 밖이면 ❌. "N년 이내·이하"는 N년 당일까지 ✅, "N년 미만"은 당일 ❌
- 날짜 조건이 있으면 날짜 비교 우선, 개월과 날짜가 둘 다 있으면 둘 다 맞아야 함
- 예비창업자: 업력 0개월로 봄 → 공고에 업력 조건이 있으면 ❌
- 기창업자인데 업력이 비어 있으면 ❔ + 되묻기

### 3-6. 사업자등록 (61건)

| 필드 | 값 | 62건 |
| --- | --- | --- |
| `값` | `필수` / `불가` / `무관` / `사후등록` | 59 / 14 / 4 / 2 |
| `기준일` | `명시없음` / `공고일` / `접수마감일` | 65 / 13 / 2 |

- 예비창업자만 → `불가` / 기업·소상공인 대상 → `필수` / "선정 후 협약 전까지 등록" → `사후등록`
- **"예비창업자 및 창업 N년 이내 기업"은 반드시 `트랙`으로 나눔** (예비창업자 트랙 `불가` / 기업 트랙 `필수` + `업력`). 최상위에 넣으면 AND로 판정돼 예비창업자가 잘못 ❌가 됨

**판정** (사용자 `창업단계`)
| 공고 `값` | 예비창업자 | 기창업자 |
| --- | --- | --- |
| `필수` | ❌ | ✅ (이미 등록, 따로 확인 안 함) |
| `사후등록` | 🟡 [선정 후 사업자등록 필요] | ✅ (이미 등록) |
| `불가` | ✅ | **❌** (예외 없음) |
| `무관` | ✅ | ✅ |

- 폐업한 사람, 창업 이력 언급이 없는 사람은 예비창업자로 봄

### 3-7. 창업이력 (4건)

| 필드 | 값 | 62건 |
| --- | --- | --- |
| `사업자이력_허용` | `폐업후허용` | 2 |
| `기준일` | `공고일` | 3 |

- 예: "사업자 등록 이력이 없는 자 (단, 폐업 후 3년 이상 경과 시 가능)"

## 채우는 법: `info_라벨링.csv`

한 줄 = 값 하나. 공고마다 8줄이 미리 들어 있다. 목록 칸(제출서류·우대사항·모집일정)은 줄을 복사해서 **항목 하나에 한 줄**씩 쓴다. 칸에 해당하는 게 원문에 없으면 `값`에 `없음`.

| 칸 | 값 | 다른 열 |
| --- | --- | --- |
| 지원규모 | 원문 문구 그대로 ("총 6억원", "30개사 내외"). 표 숫자면 단위 붙임 | |
| 최대지원금 | 만원 숫자 (1억 → 10000). 비율뿐이면 비우고 `원문`에 "총사업비의 70%" | `원문`: 금액 문구 |
| 중복지원 | 가능 / 불가 / 조건부 / 미확인 | `메모`: 무엇과 중복 불가인지 |
| 제출서류 | 서류명 (수량·형식 뺌). "택1"이면 "A 또는 B" 한 줄 | `필수`: O / X (아래), `대상`: "법인", "마이데이터 비동의 시" 같은 원문 조건 (모두 내면 비움) |
| 우대사항 | 누가 우대받는지 짧게 ("여성기업") | `가점`: 숫자 (없으면 비움) |
| 모집일정 | 차수 이름 ("1차", "일반형 1차"). 하나뿐이면 비움 | `시작`·`마감`: YYYY-MM-DD, 날짜가 정확하지 않으면 `원문`에 "5월" |

- `트랙`: 위 값이 트랙마다 다를 때만 트랙 이름(위 표의 이름 그대로)을 쓴다. 공고 전체에 해당하면 비움
- 규칙은 `docs/안내정보_스키마.md` 2절과 같다. 헷갈리는 것
    - 중복지원: **다른 사업과 동시에** 받을 수 있나만. "전에 받았으면 신청 불가"는 자격이라 넣지 않음
    - 제출서류: **신청할 때** 내는 것만. 협약 시·선정 후·합격자만 내는 서류는 뺌. 신청 때 내는 사업계획서·PPT는 넣음
    - 제출서류 필수 (11/17 결정): **"이 서류가 없으면 신청이 안 되나?"** 안 되면 필수 O, 신청은 되고 혜택만 못 받으면 필수 X
        - "사업자등록증명 (마이데이터 비동의 시)", "법인등기부등본 (법인만)" → 필수 O, 조건은 `대상`에
        - "(선택)", "가점·우대 받으려면", "자부담 면제 받으려면", "희망 시", "있으면 제출" → 필수 X, 이유는 `대상`에 (예: "자부담 면제받으려면 (은행 연계 경영컨설팅 신청 시)" → 화면: 선택 · 자부담 면제받으려면)
    - 헷갈리는 기준 17개의 결정은 `info_헷갈리는기준.csv`의 `결정` 칸 (11/17 모두 정함)
        - "임대차계약서 (해당 시)"처럼 조건이 무엇인지 원문에 있으면 그 조건을 `대상`에 쓰고 O ("사업장이 임차인 경우"). 조건을 알 수 없으면 X
    - 최대지원금: 1인(1개사)당 최대. 사업 전체 예산, 특별지역 예외 금액, 계산 예시 표의 금액은 아님
    - 모집일정: API 접수기간과 같으면 `없음`. 차수·세부사업마다 다르거나 API와 다를 때만
- 애매하면 `메모`에 적는다 (나중에 채점에서 빼거나 따로 봄)
- **지원내용은 라벨링하지 않는다** (요약문이라 정답이 하나로 안 정해짐 → 결과를 따로 검수)

서울·전국 공고 62건의 신청 자격 추출 결과입니다. 판정 입력이자 DB 적재용입니다.

| 파일 | 내용 |
| --- | --- |
| `공고_62/` | 공고마다 JSON 1개 (스키마 v0.6 + `업종.업종명`) |
| `conditions_service_v4_업종확장.json` | 62건을 합친 것 (DB 적재는 이 파일 하나로 가능) |

| `출처.csv` | 공고별 출처: 정답셋 30건(사람 검수) / LLM v4 추출 32건(+ 사람 수정) |
| `../excluded/excluded_industries.csv` | 제외업종 표준 목록 3개 (`제외_참조`가 가리키는 목록, 체크리스트 문구용) |

## 만든 방법
- 정답셋 30건: 사람이 원문과 대조해 확정한 추출 정답
- 나머지 32건: LLM 추출(프롬프트 `extract_v4.md`, gpt-6.1-terra) → 자동 검증(근거 원문 대조, 스키마) → 사람 검토 후 수정 21개 반영
- 마지막에 업종 후처리: `제외_참조`가 있으면 `excluded_industries.csv`의 업종을 `업종.업종명.제외_목록`·`제외_예외`로 복사
- 검증 결과: 근거 918개 모두 원문에 있음, 스키마 문제 0

## 스키마에서 새로 바뀐 것 (노션 스키마 3-7, 6-3 참고)
- `업종.업종명` (객체): `허용`·`제외`(원문 그대로), `제외_목록`·`제외_예외`(CSV에서 복사), `제외_별명삭제`(후처리 기록, 판정에 안 씀)
- 업종 판정은 `업종명`만 사용. `포함_대분류`·`제외_대분류`·`KSIC코드`는 남아 있지만 판정에 쓰지 않음
- 기업규모(소상공인·상시근로자·매출 상한)는 판정하지 않고 체크리스트로
- JSON의 `스키마버전` 값은 `"v0.6"` (문서 버전은 v0.8)

## 알아 둘 점
- 정답셋 30건의 `업종명` 키워드는 아직 검수 중이라 바뀔 수 있음 (바뀌면 다시 보냄)
- LLM 추출 32건은 판정 핵심 칸(신청자 유형·사업자등록·업력·나이·지역·창업이력·특수자격·보유요건·업종명)만 사람이 검토함. 제외대상·기타조건은 자동 검증만 함
- 새 공고가 들어오면: 추출 → 사람 수정 반영 → 업종 후처리(`제외_참조` → `../excluded/excluded_industries.csv` 복사) 순서. 처리 코드는 아직 저장소에 없음 (정예은 로컬)

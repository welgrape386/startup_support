# 판정 평가 데이터 48건 (2026-11-24, 정예은)

나애님 사용자 샘플 + 나주희님 라벨링에 쓴 공고 48건(`공고목록_RAG8.csv`). 구성은 `판정평가_20261119`(30건)와 같음.

| 실험 | 입력 |
| --- | --- |
| **B0** API 필터 | `API필드_48.csv` |
| **B1** LLM 판정 | `원문_48/` |
| **제안** LLM 추출 → 코드 판정 | `LLM추출_48/` |

- `LLM추출_48/`은 **48건 모두 LLM 원본 추출**. 정답 JSON이나 사람 수정은 넣지 않음 (넣으면 점수가 부풀려짐)
    - 정답셋 30에 든 27건 = `판정평가_20261119/LLM추출_30`과 같은 파일
    - 나머지 21건 = 62건 전체 추출(v4, gpt-6.1-terra) 원본
- `목록_48.csv`: 공고별 정답셋 여부, 추출 분할(개발/평가/추가), LLM 추출 출처
    - 분할 "개발" 공고는 추출 프롬프트를 고칠 때 본 공고라, 추출 쪽 점수만 보면 유리할 수 있음
- `원문_48/`, `API필드_48.csv`의 27건도 30건 패키지와 같은 파일 (기업마당 2026-10-16 스냅샷)
- `excluded_industries.csv`: 업종 제외 목록 (`제외_참조`가 가리킴)
- 대안조건 선택지가 모두 판정 불가인 곳(119802·120117·121291·123795·126965 트랙 1개)은 판정 규칙의 "체크리스트로" 문장으로 처리
- 만든 코드: `make_judge_eval48.py`

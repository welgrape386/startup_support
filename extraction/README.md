# 공고 자격조건 추출 (LLM)

공고 원문에서 신청 자격 조건·안내정보를 뽑아 JSON으로 정리하는 단계. 담당: 정예은

- 흐름: 기업마당 API 수집 → 원문 텍스트 추출(307/342건) → LLM(gpt-6.1-terra) 자격조건 추출 → 사람 검토·수정 → 업종 후처리 → 서비스 데이터 62건
- 대상: 서울·전국 공고 62건
- 이 브랜치에는 **최종본만** 있음. 버전별 중간 결과(프롬프트 v2·v3, 실행 결과 등)는 작업 폴더에 보관

## 최종 결과물

| 경로 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `service_v4/` | **자격조건 JSON 62건 (11/19본, 최신)**. 11/15본에서 127032 예비창업자 사업자등록 `불가` → `사후등록`만 바뀜 | 판정·백엔드 (main `judgment/proposal/service_v4/`는 아직 11/15본 → 교체 필요) |
| `info_v4/` | 안내정보 62건 (11/18) + `지원내용_62.csv` | 백엔드·AI 요약 |
| `handoff/판정평가_RAG48_20261124/` | 판정 2차 평가용 48건 LLM 추출 원본 + 원문 | 판정 (나주희님) |
| `excluded/excluded_industries.csv` | 제외업종 표준 목록 3개 | 판정 체크리스트 |

## 스크립트

| 순서 | 파일 | 하는 일 |
| --- | --- | --- |
| 1 | `fetch_bizinfo.py` | 기업마당 API → 공고 목록 CSV (키는 환경변수 `BIZINFO_KEY`) |
| 2 | `extract_texts.py` | 공고문 다운로드 + 텍스트 추출 |
| 3 | `run_extraction.py` | 프롬프트 + 원문 → LLM 자격조건 추출 |
| 4 | `verify_extraction.py`, `evidence_rate.py` | 스키마·허용값 검사, 근거 문장이 원문에 있는지 검사 |
| 5 | `compare_gold.py` | 정답셋과 비교 (정밀도·재현율·F1) |
| 6 | `apply_fixes.py` | 사람 검토 수정 반영 |
| 7 | `add_industry_names.py`, `expand_industry_refs.py`, `make_industry_list.py` | 업종명 추가, 제외업종 목록 펼치기, 업종명 목록 CSV |
| 8 | `build_service.py` | 서비스 데이터 62건 묶기 |
| - | `postprocess_info.py`, `verify_info.py`, `score_info.py` | 안내정보 후처리·검증·채점 |
| - | `b0_api_extract.py` | 기준선 B0 (API 칸만으로 조건 만들기) |
| - | `make_review_sheet.py`, `make_judge_eval48.py` | 검토표, 판정 2차 평가 48건 패키지 만들기 |

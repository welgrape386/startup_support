2026년 음식점 위생등급 지정업소 종합청소비 지원사업
참여업소 모집 공고
김포시에서는 「식품위생법 」 제47조의 2에 의거 음식점 위생등급 지정업소를 대상으로 ‘2026년 음식점 위생등급제 지정업소 종합청소비 지원사업’ 참여업소를 아래와 같이 모집하오니
관심있는 업소는 신청하여 주시기 바랍니다.
1. 모집개요
 ❍ 모집업소 : 50개소
 ❍ 자격요건 : 신청일 기준 위생등급제 지정 후 1년 경과한 일반·휴게음식점(식사를 주로 조리·판매)
 ❍ 지원금액 : 1개 업소당 최대 70만원 이내(연 1회 지원)
 ❍ 지원내용
  - 주방시설(닥트, 후드, 환풍기, 제빙기 등) 청소비
  - 주방, 객석, 객실의 바닥, 벽 등 청소비
 ❍ 지원제외대상
  - 차·커피·음료 등을 주로 판매하는 휴게음식점, 제과점영업
  - 위생등급제 지정 취소된 후 신청한 경우
  - 김포시 사전승인 없이 사업내용(금액, 사업범위 등)을 변경한 경우
  - 구비서류 미제출 또는 미비한 경우
  - 프랜차이즈 업소 중 본사 주도의 청소를 시행하는 경우(본사와 계약한 청소업체 이용 등)
2. 신청방법
 ❍ 신청기간 : 공고일 ~ 12. 12.(예산 소진 시 조기마감)
 ❍ 신청방법 : 이메일접수 eun5632@korea.kr 또는 방문접수(김포시 사우중로 1 제3별관 식품안전과(음식문화팀)
 ❍ 신청서류 : 신청서 서식 1, 2 각 1부 / 견적서 1부 / 청소 대상시설(청소전) 사진 4매이상 /업소 전경 사진 1매
  ※ 사업자 등록증 상 청소관련 업종이 명시된 청소업체 이용
  - 지정증 유효기간 만료 4개월 미만인 경우 : 연장신청 후 카카오톡으로 발송된 접수 문자 첨부
  - 지정증 유효기간 만료 4개월 이상인 경우 : 서식 2제출
  - 지정증 유효기간 만료 2개월 미만인 경우 : 신청불가
3. 선정방법
 ❍ 예산 소진 시까지 선착순 접수 및 선정
  ※ 신청에 따른 선정결과는 신청인 휴대폰 번호 또는 메일로 개별 통보
4. 청구방법
 ❍ 청구기간 : 선정통보 받은 후 2026. 12. 12.까지 청소 시행후 지원금 청구
 ❍ 청구방법 : 이메일접수 eun5632@korea.kr 또는 방문접수(김포시 사우중로 1 제3별관 식품안전과(음식문화팀)
 ❍ 청구서류 : 청구서 서식 3 / 청소대상 시설 사진 4매 이상 / 지출영수증 1부 / 업주 통장사본 1부 / 청소업체 사업자등록증 1부

# 지원-Fit RAG 검색 (김나애)

사용자 질문에 맞는 공고를 찾아서 판정 단계로 넘긴다. 공고마다 근거 문단도 같이 찾음

지금 검색: 키워드 + 의미 검색 → 지역 거르기(타지역·통합공고 제외, 다른 구 공고는 뒤로) → 원하는 지원 올리기, 특수 대상 공고 내리기
결과: Recall@5 0.555 / Recall@20 0.861 / MRR 0.901 (자세한 건 `04_실험_시험+채점결과/실험기록.md`)

## 백엔드에서 쓰는 법

```python
import sys; sys.path.insert(0, "rag/04_실험_시험+채점결과")
from search_service import search
search("마포구에서 디저트 카페를 준비하는 예비창업자예요", user_gu="마포구", stage="예비", need="홍보·판매")
```
인자와 결과 형식은 `search_service.py` 맨 위에 있다. 처음 부를 때 모델(bge-m3)을 불러와서 수십 초 걸림.

필요한 패키지: `pandas numpy openpyxl rank_bm25 kiwipiepy sentence-transformers`

# 지원-Fit RAG 검색 (담당: 김나애)

목표: 사용자 질문에 맞는 공고와 자격 조건 문단을 상위에 찾아오기
평가: V0 키워드 → V1 의미 → (하이브리드) → V2 필터·원문 → V3 reranker, 단계별 Recall@5 · MRR · nDCG@5 비교

폴더 번호 = 작업 순서. 데이터는 왼쪽(01)에서 오른쪽(04)으로 흐른다.

```
01_원본 ──▶ 02_검색대상_시험지 ──▶ 04_실험_시험+채점결과 ◀── 03_평가셋_문제+답안지
(팀 원본)    (시험지)         (응시+채점)   (문제+답안지)
```

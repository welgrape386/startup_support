# 지원-Fit RAG 검색 (김나애)

사용자 질문에 맞는 공고를 찾아서 판정 단계로 넘긴다. 공고마다 근거 문단도 같이 찾음

지금 검색 순서
1. 키워드 + 의미 검색 (질문 뒤에 원하는 지원 단어를 붙여서 찾음)
2. 지역 거르기: 타지역·통합공고·원문 없는 공고·폐업 전용 공고 빼고, 다른 구 전용·지방 운영 공고는 뒤로
3. 상위 40개 안에서 순서 조정: 원하는 지원 올리기, 특수 대상·업종 안 맞는 공고·나이 안 맞는 공고 내리기
4. 20개를 판정으로 넘김

결과 (#32): Recall@5 0.683 / Recall@20 0.977 / MRR 0.944 / nDCG@5 0.771
개별 공고 기준, 질문 27개, 답안지 1049줄. 자세한 건 `04_실험_시험+채점결과/실험기록.md`

## 백엔드에서 쓰는 법

```python
import sys; sys.path.insert(0, "rag/04_실험_시험+채점결과")
from search_service import search
search("마포구에서 디저트 카페를 준비하는 예비창업자예요",
       user_gu="마포구", stage="예비", need="홍보·판매",
       industry="디저트 카페", industry_cat="음식·카페", age=29)
```

| 인자 | 값 | 어디서 |
| --- | --- | --- |
| `query` | 사용자 문장 그대로 | 입력 |
| `user_gu` | 서울 구 이름. 예비면 창업 예정 구, 개업이면 사업장 구 | 사용자 추출 `검색지역` |
| `stage` | 예비 / 개업 / 폐업 (사업자이력 그대로, 모르면 빈칸. 폐업은 예비처럼 봄) | 사용자 추출 `사업자이력` |
| `need` | 원하는 지원 1개, 없으면 `미지정` | 사용자 추출 `필요지원` |
| `industry` | 업종 원문 ("디저트 카페") | 사용자 추출 `업종원문표현` |
| `industry_cat` | 업종 카테고리 1~2개, `\|`로 구분 | 사용자 추출 업종 카테고리 |
| `age` | 만 나이 | 사용자 추출 나이 |

결과 형식은 `search_service.py` 맨 위에 있음. 처음 부를 때 모델(bge-m3)을 불러와서 수십 초 걸림.
`02_검색대상_시험지/industry_map.csv`, `age_map.csv`가 없으면 업종·나이 내리기는 꺼진 채로 돎.

필요한 패키지: `pandas numpy openpyxl rank_bm25 kiwipiepy sentence-transformers`

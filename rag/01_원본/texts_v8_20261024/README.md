# 기업마당 범위 공고 텍스트 (v8, 2026-10-24)

- 입력: 기업마당 API 전체 1477건 중 서비스 범위(스키마 v0.1 0절) 342건 (v4의 314건 + 초기창업 관련 28건)
- texts/{공고ID}.txt: 텍스트 추출에 성공한 307건만 (UTF-8)
- extract_report.csv: 342건 전체 결과 (형식, 상태, 글자수, 오류, 1차결과)
- format_success_rate.csv: 형식별 성공률
- extract_failures.csv: 실패 35건 (공고URL·파일URL·다른 첨부 포함)
- goldset_candidates.csv: 정답셋 후보 302건 (성공 307건 중 일부누락의심 5건 제외). 범위기준(①②③), 지원대상, 형식, 글자수, 텍스트 파일 경로 포함

## 실패 35건
- 이미지로 된 파일 33건 (이미지 PDF 22, jpg 5, png 6) + 2단 편집이라 왼쪽·오른쪽 내용이 섞인 PDF 2건 (120234, 119754, 상태 `추출실패(2단편집)`). 포스터·홍보물이 대부분이고 스캔된 공고문도 일부 있음
- texts/에는 없음 → 필요하면 API 사업개요(bsnsSumryCn)로 대체
- extract_report.csv의 상태값은 '추출실패', '텍스트거의없음(이미지추정)', '추출실패(2단편집)' 세 가지 → 실패 목록은 extract_failures.csv 사용

## 추출 방식
- 기본은 API 본문출력파일(printFileNm). 이름에 '공고'가 없거나 텍스트를 못 얻으면 첨부의 '공고' 문서 사용 (342건 중 3건)
- PDF: 읽는 순서 정렬, 띄어쓰기 누락 보정. hwp: 4바이트 글자 처리. 한컴 기호는 ①~⑩ 또는 □로 변환
- 공백 정리: 3칸 이상 공백 → 2칸, 빈 줄 여러 개 → 1개
- PDF는 글자 좌표로 줄을 다시 조립 (v6): 밀린 쉼표·괄호를 제자리에, 겹쳐 그려진 같은 글자(그림자 효과)는 하나만
- PDF의 Wingdings 글머리 기호를 원래 기호로 복원 (v7): "m 접수기한" → "❍ 접수기한"
- `extract_report.csv`의 `일부누락의심`=True 5건은 강조 글자가 그림으로 저장돼 일부가 빠짐 (OCR 전까지 주의)

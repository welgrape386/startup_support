## 화면에 쓸 때
- **트랙이 있는 공고 (18건)**: 트랙 이름으로 탭을 만들고, 탭마다 최상위 값 + 그 트랙 값을 보여줌 (한 값 칸은 트랙 값이 있으면 그것, 목록 칸은 최상위 뒤에 트랙 목록을 붙임). 사용자가 탭을 고름
- **제출서류 `필수`**: true = 이 서류가 없으면 신청이 안 됨 / false = 신청은 되지만 혜택을 못 받거나 선택 서류. `대상`에 조건이나 이유 ("마이데이터 비동의 시", "자부담 면제받으려면")
- **모집일정**: 비어 있으면 API 접수기간을 씀. 값이 있으면 원문 날짜를 씀. `시작`·`마감`이 null이고 `원문`만 있으면 "5월", "2월 중"처럼 글자로 표시

## 만든 방법
- 프롬프트 `info_v4.md` + gpt-6.1-terra로 62건 추출 → 후처리 → 자동 검사
    - 프롬프트는 개발 15건을 보며 v1 → v4로 개선 (v2: 최대지원금 원문 짧게, 예외 금액 제외 / v3: 표 단위, 계산 예시 제외, 모집일정 원문 / v4: 택1 서류 한 줄)
    - 후처리: 금리·자부담 삭제, 모든 트랙에 같은 목록 항목은 최상위로, 줄바꿈 정리, 조건 붙은 서류 필수 처리, 사람 수정 2개 (127032 창업기획서 PPT 추가, 최대지원금 1,900만원)
    - 자동 검사: 근거 문장이 원문에 있는지, 숫자가 근거에 있는지, 최대지원금 만원 환산, 단위 누락 등. 62건 문제 3개 (근거 문장 2, 숫자 1)
- 처리 코드(`run_extraction.py`, `postprocess_info.py`, `verify_info.py`, `score_info.py`)는 아직 저장소에 없음 (정예은 로컬)
